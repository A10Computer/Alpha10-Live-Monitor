Schlanker Live-System-Monitor für Windows – CPU, RAM, GPU, Netzwerk, Datenträger und Prozesse in Echtzeit, in einem modernen Dark-Theme-Dashboard.

## Features

- CPU-Auslastung inkl. Kernanzeige mit P-/E-/H-Kern-Markierung (Hybrid-CPUs)
- Arbeitsspeicher inkl. Auslagerungsdatei-Größe
- GPU: Kartenname, live VRAM-Nutzung und Auslastung
- Netzwerk-Live-Graph mit Adaptername
- Datenträgerübersicht, Top-Prozesse (sortierbar, mit Beenden-Funktion)
- Mini-Modus (kompaktes Always-on-Top-Widget) & Tray-Modus
- Zwei Themes, Session-Spitzenwerte
- Deutsch & Englisch mit automatischer Erkennung, per Klick umschaltbar

## Datenschutz

Alles bleibt lokal: keine Datenübertragung, keine Server-Verbindung, kein Tracking. Eine kleine Einstellungsdatei wird nur im eigenen Windows-Profil gespeichert, und nur wenn du das beim Beenden ausdrücklich bestätigst.
